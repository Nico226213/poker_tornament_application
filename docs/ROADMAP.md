# 🃏 Poker Tournament Timer — 開発ロードマップ

## 🎯 プロジェクト概要
ブラウザ上でポーカーのトーナメント進行を管理・表示できるアプリケーション。  
主催者がブラインド構成を作成し、タイマーで進行を管理。  
将来的にはプレイヤー登録や平均スタック表示、ミラー画面表示などを実装予定。

## 🧱 フェーズ詳細

### **M0 — リポジトリ初期化**
- README / .gitignore / docs/ROADMAP.md の作成  
- 開発目的・マイルストーンの明文化  
- mainブランチと運用方針決定

---

### **M1 — 環境構築**
**目的：** 開発環境のベースを整備する。  
- Vite + React + TailwindCSS のセットアップ  
- React Router 導入（SetupPage / PlayPage）  
- レイアウト・テーマ基礎（ダークモード考慮）  
- 初期ページ遷移が動作する状態をコミット

---

### **M2 — トーナメント設定画面**
**目的：** トーナメント構成をGUIで作成できるようにする。  
- レベル追加・削除・編集（SB, BB, Ante, 時間）  
- 休憩（Break）レベルのサポート  
- localStorage に保存・ロード  
- 構成データをJSONでエクスポート可能に  
- 簡易バリデーション（入力漏れチェック）

---

### **M3 — 進行画面（MVP）**
**目的：** トーナメントを進行・表示する基本機能を実装。  
- タイマー（カウントダウン、停止、リセット）  
- 現在レベル / 次レベル表示  
- 「次へ」「前へ」ボタンによる手動操作  
- 音・画面でレベル終了通知  
- モバイルでも見やすいUI設計  

🟩 **→ このフェーズで MVP 完成**

---

### **M4 — 設定保存・永続化**
**目的：** トーナメントの再開や複数構成の管理を可能にする。  
- localStorage への自動保存  
- 複数トーナメントの保存・ロード  
- リセット機能（新しいトーナメント開始）  
- データ構造リファクタリング

---

### **M5 — プレイヤー管理**
**目的：** 参加プレイヤー数に基づいて平均スタックなどを表示。  
- プレイヤー登録・削除機能  
- トータルスタックとアベレージ表示  
- リバイ（再エントリー）対応  
- シート再配置など将来機能の基礎設計

---

### **M6 — トーナメント情報共有**
**目的：** 作成したトーナメントを他デバイスと共有可能にする。  
- JSONエクスポート/インポート機能  
- QRコード生成・読み込み  
- URL共有リンク（Firebase経由など）

---

### **M7 — 観客用ミラー画面**
**目的：** 店内モニター等で進行情報を表示できるようにする。  
- フルスクリーン表示モード  
- 現在レベル・残り時間・次レベル・平均スタック表示  
- デザインをシンプルに（文字大きめ）  
- リアルタイム同期対応の準備

---

### **M8 — リアルタイム同期**
**目的：** 複数デバイス間でトーナメント状態を同期。  
- Firebase Realtime Database or WebSocket導入  
- 管理端末 ↔ 観客端末間のステート同期  
- 通信エラー・オフライン耐性

---

### **M9 — 認証・権限管理**
**目的：** 管理者・観客の操作を区別する。  
- Firebase Authentication / Google Login  
- ロール（admin, viewer）制御  
- セキュリティルール設定

---

### **M10 — PWA / モバイル最適化**
**目的：** スマホやタブレットでの快適動作。  
- PWA対応（オフライン・ホーム画面追加）  
- レスポンシブデザイン最適化  
- タッチ操作・スワイプ対応

---

### **M11 — UI/UX改善**
**目的：** デザイン性と操作性を向上。  
- Tailwind + shadcn/ui コンポーネント導入  
- カラーテーマ切替（ダーク / ライト）  
- アニメーション（Framer Motion）  
- レベル終了音 / バイブレーション対応

---

### **M12 — デプロイ**
**目的：** 実際に運用できる状態にする。  
- Vercel / Firebase Hosting へのデプロイ  
- バージョン付け・タグ付け  
- README・ドキュメント更新  
- 公開URL共有
